Library Book Issue & Return System (Console Version)
Project Description

The Library Book Issue & Return System is a console-based application developed to simplify library management operations. The project allows librarians to manage books, register members, issue and return books, search records, and generate reports efficiently through a command-line interface. The system will use C++ for implementing core logic, file handling, and menu-driven operations, while text files will be used for permanent data storage.

Core Features
Add and manage books
Search books by title or author
Register library members
Issue books to members
Return books and update availability
Fine calculation for overdue books
Reports for available and issued books
File handling for permanent data storage
Menu-driven console interface
AI Feature Description

The project includes a simple AI-based book recommendation feature. Based on the category or author of previously issued books, the system will suggest similar books to users. This improves user experience and demonstrates intelligent system behaviour.
